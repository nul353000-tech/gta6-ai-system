GTA 6 AI SYSTEM — API
====================

CONTENU DU DEPOT
- app.py : API FastAPI, tableau de bord, synchronisation protégée et analyse IA texte/image.
- web/GTA6_AI_SYSTEM.html : tableau de bord web responsive V1.3 avec sessions, objectifs,
  checklist, planificateur, journal, voix navigateur, export/import et aperçu de capture.
- run-local.ps1 : installation et lancement local Windows, avec option LAN explicite.
- Dockerfile, requirements.txt et render.yaml : configuration de l'API et du déploiement.
- tests/ : tests automatisés sans appel réseau au fournisseur IA.

Le tableau de bord web fonctionne dans un navigateur Android ou PC. Aucun APK Android natif
n'est fourni et le logiciel ne contrôle pas le jeu ou la manette.

CONFIGURATION
- APP_ACCESS_TOKEN : jeton Bearer long et aléatoire, à configurer dans le client.
- AI_PROVIDER : `auto` (défaut, Gemini si GEMINI_API_KEY existe, sinon OpenAI), `gemini` ou `openai`.
- GEMINI_API_KEY : clé Google AI Studio, conservée uniquement côté serveur. Gemini 2.5 Flash
  est le modèle par défaut et son niveau gratuit accepte texte et images selon les quotas.
- GEMINI_MODEL : modèle Gemini, valeur par défaut `gemini-2.5-flash`.
- OPENAI_API_KEY : clé API OpenAI, conservée uniquement côté serveur si OpenAI est utilisé.
- OPENAI_MODEL : modèle OpenAI Responses, valeur par défaut `gpt-6.1-terra`.

Ne commitez jamais de clés ou jetons. Le endpoint /health vérifie que le processus répond ;
il ne vérifie pas les identifiants des fournisseurs. Sans la clé du fournisseur sélectionné,
/v1/assistant renvoie une erreur de configuration.

API
- GET / : tableau de bord web.
- GET /health : contrôle de disponibilité.
- GET/POST /api/state : synchronisation JSON avec authentification Bearer ; maximum 2 Mo.
- POST /v1/assistant : en-tête Authorization: Bearer <APP_ACCESS_TOKEN> et JSON
  {"prompt":"...", "image_data_url":"data:image/png;base64,..."} (image facultative).
- Les images JPEG, PNG, WebP et GIF sont limitées à 5 Mo ; les octets sont vérifiés
  par signature avant leur envoi au fournisseur.
- `AI_PROVIDER=auto` utilise Gemini dès que `GEMINI_API_KEY` est configurée ; sinon il utilise
  OpenAI. `AI_PROVIDER` permet de forcer le fournisseur.
- Gemini est appelé avec `generateContent` et OpenAI avec Responses (`store=false`). L'historique
  conversationnel n'est pas conservé côté serveur.
- Sur le niveau gratuit Gemini, Google indique que les requêtes peuvent être utilisées pour
  améliorer ses produits. Évite d'y envoyer des images ou données sensibles.
- Le limiteur de débit est en mémoire du processus : il convient à une instance unique et
  doit être remplacé par un stockage partagé si le service Render passe à plusieurs instances.
- Les sauvegardes serveur locales sont écrites dans `.local-state.json` (ignoré par Git).
  Le disque Render est éphémère ; exporte tes données si tu utilises le tableau de bord en ligne.

LIMITES DU SERVICE
- L'API ne reçoit pas le flux PS Remote Play et n'envoie aucune commande à la PS5.
- Les requêtes n'incluent que le prompt et l'image fournis ; l'historique local d'un éventuel
  client n'est pas transmis automatiquement.
- Les réponses IA peuvent être inexactes. Les instructions demandent de distinguer les faits
  confirmés des hypothèses et des informations inconnues sur GTA 6.

DEPLOIEMENT RENDER
Le service Render existant utilise les fichiers de la racine. Pour activer Gemini, créer une
clé dans Google AI Studio et ajouter `GEMINI_API_KEY` dans Environment dans Render. Le code
sélectionnera Gemini automatiquement dès qu'il voit cette variable ; sinon il conserve OpenAI.
Les quotas gratuits sont limités et peuvent changer. Les secrets restent dans Render.

LANCEMENT LOCAL SOUS WINDOWS
- Ouvrir PowerShell dans le dossier du dépôt et lancer
  `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run-local.ps1`.
- Le script crée l'environnement Python, installe les dépendances, génère un jeton local et
  demande la clé Gemini dans une invite masquée. La configuration est enregistrée dans `.env`.
- `.env` est ignoré par Git ; ne le partage pas et ne le commite pas.
- Ouvrir `http://127.0.0.1:8000`, puis dans Réglages saisir le `APP_ACCESS_TOKEN` enregistré
  localement dans `.env`. Le jeton reste dans la mémoire de l'onglet.
- Pour afficher seulement ce jeton dans une autre fenêtre PowerShell, exécuter
  `(Get-Content .env | Where-Object { $_ -like 'APP_ACCESS_TOKEN=*' }) -replace '^APP_ACCESS_TOKEN=',''`.
  Ne partage pas le résultat.
- Pour synchroniser un téléphone sur le même Wi-Fi privé, lancer avec `-Lan` et saisir le même
  jeton sur Android. Le mode LAN écoute sur le réseau local : ne l'utilise pas sur un Wi-Fi public
  et n'expose pas le port 8000 sur Internet.
- Le contrôle local est disponible sur `http://127.0.0.1:8000/health`.
- Arrêter le serveur avec Ctrl+C. Pour le relancer, exécuter la même commande ; la clé n'est
  demandée que si elle manque dans `.env`.

TESTS
Installer les dépendances de développement avec `pip install -r requirements-dev.txt`,
puis lancer `pytest`. Les tests simulent les fournisseurs et ne nécessitent aucune clé réelle.
